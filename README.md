# Páginas

Hábito de leitura e biblioteca virtual para Windows e Android: metas diárias, sequência de dias, milhares de livros em domínio público para ler no app, grifos e uma IA que explica os trechos difíceis. Sincroniza pela conta Google.

**Baixar:** https://limabat.github.io/paginas/

Como publicar e configurar: veja [LEIA-ME.md](LEIA-ME.md).
