Metas pequenas, sequência de dias, milhares de livros gratuitos para ler dentro do app e uma inteligência artificial que explica qualquer palavra ou frase difícil. De graça, para Windows e Android.

⬇ Baixar para WindowsPaginas.bat ⬇ Baixar para AndroidPaginas.apk

Sempre a versão mais nova. Os dois sincronizam pela sua conta Google.

Como instalar no Windows
  1. Clique em Baixar para Windows. Se o navegador perguntar, escolha Manter.
  2. Dê dois cliques em Paginas.bat. Se aparecer "O Windows protegeu o computador", clique em Mais informações > Executar assim mesmo.
  3. Pronto: o Páginas abre numa janela própria e cria um atalho na Área de Trabalho e no menu Iniciar. Não precisa instalar mais nada.
Como instalar no Android
  1. No celular, toque em Baixar para Android e abra o arquivo Paginas.apk quando o download terminar.
  2. Se aparecer "Por segurança, seu telefone não tem permissão para instalar apps desta fonte", toque em Configurações, ative Permitir desta fonte e volte.
  3. Toque em Instalar. Se o Google Play Protect avisar sobre um app desconhecido, toque em Mais detalhes > Instalar mesmo assim.

Funciona no Android 8 ou mais novo. O app avisa quando sair uma versão nova.
